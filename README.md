In engineering mathematics (specifically Linear Algebra), students transition from 2D vector math to higher-dimensional spaces. 
Two of the most critical foundational subspaces of a matrix A are:
The Row Space: The span of the rows of matrix A (living in the input space R^3).
The Column Space: The span of the columns of matrix A (living in the output space R^3).
This app provides an interactive 3D sandbox where you can alter a 3 X 3 matrix and instantly see how these two geometric spaces morph, 
change dimension (from lines to planes to 3D volumes), and relate to core concepts like Rank and Linear Independence.
